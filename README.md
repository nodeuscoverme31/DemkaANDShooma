# Две души

Интерактивная анкета для независимого исследования двух жизненных путей.

Открыть приложение после включения GitHub Pages: https://nodeuscoverme31.github.io/DemkaANDShooma/

Данные сохраняются локально в браузере. Экспорт JSON содержит личные ответы в незашифрованном виде. Не публикуйте файлы с ответами в этом репозитории.

Для публикации: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
